# Font assets

`PixelOperatorSC-Bold.ttf` — Pixel Operator SC Bold by Jayvee Enaguas
(HarvettFox96), released under Creative Commons Zero v1.0 Universal (CC0,
public domain). Upstream: https://notabug.org/HarvettFox96/ttf-pixeloperator

The energy panels draw their baked-in artwork labels with this face. It is a
pixel font, so it renders hard-edged at 8px steps with anti-aliasing off, which
a hinted desktop font cannot do on a 128x128 LED panel.
