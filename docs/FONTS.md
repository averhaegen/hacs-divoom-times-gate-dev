# Device fonts: test notes & recommendations

The **authoritative catalog** (all 308 font ids with exact charsets) lives in
FONTS_CATALOG.md, generated by `scripts/get_font_list.py` from the cloud
endpoint `Device/GetTimeDialFontList` (works with `DeviceId` + `DeviceType:
"LCD"` params; returns an empty list without them). Glyphs outside a font's
charset are **silently dropped** by the device — verified live 2026-07-05,
the catalog charsets matched every on-device observation exactly.

## Shortlist (hand-tested on the device + catalog-confirmed)

| Font | Size | Charset (exact) | Use for |
|---|---|---|---|
| 34 | 5×5 | digits + `km-/:%cf` + A–Z + `ud.+~#` | Tiny all-rounder |
| 46 | 5×13 | digits + `km./:%cf` | Small values with `%`/`k`/`m` units |
| 48 | 7×9 | digits + A–Z + a–z (no symbols!) | Unit text like `kWh` — no `%` or `.` |
| 76 | 6×14 | digits only | Bare integers |
| 84 | 6×10 | digits only | Bare integers |
| 184 | 12×14 | digits + `KMLIVEOFN.` | Medium values, decimal point |
| 246 | 18×22 | digits + `.` | Large clean values |
| 248 | 11×11 | digits + `+-%.` + `ADEFHIMNORSTUW` + `cf` | Values with `%`, `+/-`, limited caps |
| 254 | 11×14 | digits + `-cf` | Temperatures (`21c`) , negatives |
| 256 | 29×23 | digits + `:` (dual-color image font) | Big clock look |
| 260 | 23×20 | digits + `.` | Big values with decimals |

## Hard facts

- **No font in the entire 308-font catalog contains `€` or `°`.** Format
  currency as `$` (F160/F170), `EUR` text, or put the unit in the label;
  temperatures as `21c` (F254's `c`/`f` exist for exactly this) or `21.5 C`.
- `%` lives in: 26, 34, 46, 80, 170, 248 (among others — check the catalog).
- Bitmap "standard" fonts (2, 4, 32) report empty charsets in the catalog but
  render general text (they're the classic full bitmap fonts; 2 and 4 are the
  integration defaults for labels/values).
- Regenerate the catalog: `python3 scripts/get_font_list.py <DEVICE_ID>`.
